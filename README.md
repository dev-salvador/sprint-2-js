# Site com sistema de Login + Cadastro

Um sistema simples de **Login, Cadastro e Logout** feito com **HTML, CSS e JavaScript**, utilizando `localStorage` para armazenar dados localmente.

---

# 📌 Funcionalidades

## Cadastro
- Criação de usuário
- Criação de senha
- Armazenamento local via `localStorage`

## Login
- Verificação de usuário e senha
- Redirecionamento para página inicial

## Logout
- Remove sessão ativa
- Retorna para tela de login

## Interface
- Design moderno
- Botões estilizados
- Inputs personalizados
- Animações com imagens orbitando em círculo
